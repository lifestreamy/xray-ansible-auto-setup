# Что запланировано, что в работе, что уже сделано

Любые сроки — просто ориентиры, не обещания. Порядок может меняться.

## Высокий приоритет

- **[Конфигурация]** — рефакторинг: свести `roles/xray_vpn/defaults/main.yml`, `group_vars/all.yml` и `inventory.yml` в одну директорию (`config/`), убрать дублирование дефолтов. Сейчас 8 переменных из `defaults/main.yml` продублированы в `group_vars/all.yml` теми же значениями. Ориентир: 0.4.
- **[Тесты]** — автотесты развёртывания: локальный прогон на компьютере после правок, без трогания личного VPS. Проверяют, что сервер разворачивается, клиент подключается и трафик выходит наружу. Идея: Ansible-роль против локального контейнера (molecule + docker), smoke-проверки с реальным клиентом внутри теста. Ориентир: после 0.3.

## Средний приоритет

- **[Инфраструктура]** — уход с Docker на Podman или другие варианты для лучшей производительности, меньшего пинга и т. п. Ориентир: пока нет — исследовательский пункт.
- **[Клиент]** — собственный визуальный клиент: мультиплатформенный, с простым интерфейсом для развёртывания и управления. Ориентир: после 0.3.
- **[Скрипты]** — переписать обёртки на универсальный Python (работает на всех платформах). Старые `provision-vpn.sh` и `Provision-VPN.ps1` помечаются deprecated: остаются рабочими для совместимости, но не развиваются. Ориентир: после 0.3.
- **[Скрипты]** — все параметры запуска как CLI-флаги: `warp_enabled`, `num_clients`, `xray_port`, `reality_camouflage_domain` и остальные — чтобы не править yml-файлы руками. Ориентир: после 0.3.
